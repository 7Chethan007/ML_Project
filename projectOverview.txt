Project Overview
This project fetches financial data (Balance Sheet, Profit & Loss, Cash Flow) from an API, performs machine learning operations to generate insights, and stores results in a MySQL database. Real-time analysis is displayed in the terminal and on a web page for easy access and visualization.

Tech Stack
Programming Language: Python
Database: MySQL
Tools: VS Code
Packages: Pandas, Requests, SQLAlchemy, Scikit-learn
Frontend Web App: Custom-built for real-time analysis display

Project Workflow
1. Fetch Financial Data
Send company IDs one by one to the API endpoint to retrieve Balance Sheet, Profit & Loss, and Cash Flow statements.

2. Perform Machine Learning Operations
Generate insights by analyzing financial data and categorizing metrics into pros (values > 10%) and cons (values < 10%). Titles are added dynamically based on the company.

Pros (Values > 10%)
Company is almost debt-free.
Company has reduced debt.
Company has a good return on equity (ROE) track record: 3 Years ROE 47.4%
Company has been maintaining a healthy dividend payout of 66.2%
Company has delivered good profit growth of 23.0%
Company's median sales growth is 28.3% of last 10 years
Cons (Values < 10%)
The company has delivered a poor sales growth of 9.5% over past five years.
Company is not paying out dividend.
The company has delivered a poor sales growth of 9.72% over past five years.
Company has a low return on equity of 8.33% over last 3 years.
Select up to 3 pros and cons that best match the data for each company.

Sample Analysis Output
Sample Financial Analysis
Sample output showing financial analysis with pros (e.g., debt-free, high ROE) and cons (e.g., low sales growth, no dividend).

3. Store Results in MySQL
Save generated insights, pros, and cons into a pre-existing MySQL database (table: ml).

4. Display Real-time Analysis
Output results to the terminal and display them on a web page for real-time monitoring.
